# Домашнее задание к работе 2
## Условие задачи
Стоимость погонного метра красного шелка стоит Х золотых. Сколько заплатил Грей за ткань для своей бригантины если общая площадь парусов на ней S м2, а ширина ткани в рулоне L см.
## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявить константы:
   - `X` = 10 Стоимость погонного метра красного шелка (в золотых).
   - `S` = 20 Общая площадь парусов (м^2).
   - `L` = 40 Ширина ткани в рулоне (см).
3. Перевести ширину ткани из см в м:
   - `L_meters` = `L/100`
4. Вычислить длину ткани в метрах:
   - `length` = `S / L_meters` 
6. Вычислить стоимость:
   - `total_cost` = `X` * `length` 
7. **Конец**

## 2. Реализация программы

#include <stdio.h>

#include <locale.h>

int main() 

{

    int X = 100, S = 200, L = 400;
    
    setlocale(LC_ALL, "RUS");
    
    int L_meters = L / 100;
    
    int length = S / L_meters;
    
    int total_cost = X * length;

    printf("Грей заплатил %d золотых за ткань.\n", total_cost);

    return 0;
}
